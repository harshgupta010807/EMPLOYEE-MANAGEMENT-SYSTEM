
# Employee Management System

## Project Description
Employee Management System is a Python-based application used to manage employee records easily.

This project uses Python and SQLite database to store employee information permanently.

## Features
- Add New Employee
- View All Employees
- Delete Employee
- Store Employee Details

## Technologies Used
- Python
- Tkinter
- SQLite Database

## Database Details
The system stores the following employee information:
- Employee ID
- Employee Name
- Department
- Salary
- Email

## How to Run
1. Install Python on your computer.
2. Download the project files.
3. Open Terminal in the project folder.
4. Run the following command:

   python3 main.py

## Conclusion
This project helps users manage employee records in a simple and organized way.
